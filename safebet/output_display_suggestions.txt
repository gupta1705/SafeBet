SafeBet Scanner — Complete Output Reference & Decision Guide
=============================================================

This document lists every data point produced by the SafeBet backend,
its plain-English explanation, and how it affects your investment decision.

================================================================================
1. OVERALL SCORE & METADATA
================================================================================

┌─────────────────────┬────────────────────────────────────────────────────────┐
│ Field               │ What It Means                                          │
├─────────────────────┼────────────────────────────────────────────────────────┤
│ Token Address       │ The contract address of the scanned token.             │
│ Token Name          │ The registered name of the token (e.g., Tether USD).   │
│ Token Symbol        │ The ticker symbol of the token (e.g., USDT).           │
│ Trust Score (0-100) │ Composite safety rating. Higher = safer.               │
│ Score Band          │ Letter grade: LOW / MODERATE / HIGH / CRITICAL RISK.   │
│ The Catch           │ AI-written 1-liner explaining the biggest danger.      │
│ Verdict             │ Multi-sentence AI summary of the full risk profile.    │
│ Scan Duration       │ How long the full analysis took (seconds).             │
│ Flag Explanations   │ Dictionary of dynamically generated plain-English      │
│                     │ explanations and decision impacts for every flag.      │
└─────────────────────┴────────────────────────────────────────────────────────┘

DISPLAY: Card header for token details. Animated circular gauge for Trust Score with 
glow effect, color-coded band pill, "The Catch" as a red-accented alert banner, 
Verdict as a card with left border.

tax_is_changeable)          │                                              │

Proxy Trap                  │ Upgradeable contract + live owner.           │ The dev can swap the contract to ANYTHING.
(proxy_trap_active)         │                                              │ A drain function, a block-all-sells, anything.
────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────

4. MODULE 3 — MARKET & COLLAPSE ANALYSIS DATA
================================================================================
Purpose: Simulates what happens to your money if large holders sell.

FIELD                         │ BRIEF EXPLANATION                            │ DECISION IMPACT
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Liquidity Metrics             │ Total USD in the trading pool, pool tokens,  │ <$10K = wild swings on small trades.
(liquidity_usd, pool ratios)  │ and ETH reserves.                            │ >$100K = stable, clean exits possible.
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Liquidity Lock                │ Can the dev drain the trading pool? Details  │ Unlocked = classic rug-pull setup. One TX
(liquidity_locked, lock_expiry│ if locked, who locked it, and for how long.  │ can remove ALL pool funds, price → $0.
days_until_unlock)            │                                              │
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
LP Verification               │ On-chain check if LP tokens burned/locked.   │ >80% secured = strong protection.
(lp_lock_method, lp_burned,   │ Percentages for burned vs locked liquidity,  │ <30% = most LP tokens are withdrawable.
lp_total_secured_percent)     │ specific locker names, and consequence text. │
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Top Holder Stats              │ Largest single wallet address and share %.   │ >30% = extreme. Their sell would crash price.
(top_holder_percent)          │                                              │
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Top 5 Holders %               │ Combined supply held by top 5 wallets.       │ >60% in 5 wallets = coordinated selling
(top_5_holder_percent)        │                                              │ would be catastrophic.
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Dump Impact %                 │ Price drop if top holder sells everything.   │ >50% = you'd lose over half instantly.
(dump_price_impact_percent)   │                                              │
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Cascade Impact %              │ Total drop if top 5 sell sequentially.       │ >70% = near-total loss in panic scenario.
(cumulative_dump_impact_%)    │                                              │
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Holder Grade (holder_grade)   │ Overall token distribution health grade.     │ A = well distributed, F = concentration
                              │                                              │ so extreme it's nearly certain rug risk.
──────────────────────────────┼──────────────────────────────────────────────┼───────────────────────────────────────────────
Investment After Dump         │ What your $100 becomes if top holder dumps,  │ Direct dollar impact on YOUR position.
                              │ vs if the top 5 whales cascade dump.         │

DISPLAY:
  • Liquidity Depth Meter — horizontal bar with $10K/$50K/$100K thresholds
  • Holder Distribution — Chart.js doughnut showing Top 1 / Top 2-5 / Rest
    with color-coded segments (red / orange / green)
  • Cascade Waterfall — Chart.js bar chart showing $100 → after top 1 →
    after top 5, with declining bars
  • LP Lock Visual — Ring gauge with lock/unlock icon and % secured
  • Investment Impact — Before/After calculator with progress bars
